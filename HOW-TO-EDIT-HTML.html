How to edit your website text

A plain-language guide to changing the words on your site by hand — and what a CMS would add if you’d rather not touch any code. No experience needed.

First, the big picture Your website is made of files. Changing text means opening a file, finding the words, and typing over them — the same as editing a letter in a word processor, except the words sit between little code “tags.” You only ever change the words, never the tags. Always keep a backup copy of a file before you edit it, so you can undo.

Part 1 — Editing the text yourself

What you’ll need

Any plain-text editor. On a Mac, TextEdit works (open it, then choose Format → Make Plain Text). On Windows, Notepad works. Better free options that colour-code the tags and make it much easier are Visual Studio Code or Sublime Text — worth installing if you’ll edit often.

The one rule

Change only the words between the > and < symbols. Leave everything that looks like <p> or <h1> alone. For example, here is a line from your site:

<p class="lead">Karee Davidson — a Canadian portrait photographer.</p>

You would change only the highlighted words. Keep the <p class="lead"> at the start and the </p> at the end exactly as they are.

Step by step

1
Make a backup. Copy the file first (e.g. duplicate index.html and name it index-BACKUP.html). If anything goes wrong, you can put the backup back.
2
Open the file in your text editor.
3
Find your words. Use Edit → Find (Cmd+F / Ctrl+F) and search for a few words you want to change. That jumps you straight to the spot.
4
Type your change, touching only the words between the tags.
5
Save (Cmd+S / Ctrl+S). If using TextEdit, make sure it saves as plain text with the .html ending, not .txt.
6
Check it. Double-click the file to open it in your web browser and confirm it looks right before it goes live.
7
Upload it to your host (or send it to PagePros to put live).

Changing the size of a big heading

Some headings have a size setting that looks like this:

style="font-size: clamp(2.4rem, 5.2vw, 5rem);"

Change only the last number (here, 5rem). Bigger number = bigger text; smaller = smaller. Try values between 3rem and 6rem. The first two numbers control the size on phones — leave them be.

A few things that will save you grief

  • Curly “smart quotes” are fine in your words. Just don’t delete the straight quotes " that are part of the tags.
  • If you want an & symbol in your text, type &amp; — that’s how the site shows an ampersand.
  • Don’t delete a </p>, </h1> or similar closing tag. If a chunk of the page suddenly looks broken, a missing closing tag is almost always why — restore your backup and try again.
  • When in doubt, change one small thing, save, and check it in the browser before moving on.
What hand-editing can’t do Adding or removing whole photos, changing the layout, or connecting the real client galleries are developer tasks, not text edits. For those, talk to PagePros.

Part 2 — Editing without any code (a CMS)

If editing files sounds like more than you want to take on, the alternative is a CMS (content management system). A CMS adds a private login to your site. You sign in, see your text in simple boxes, type your changes, and click save — no files, no tags, no code. The site’s design stays exactly as it is now.

This is a setup task for your web person (PagePros), not something that lives in these files. For a hand-built site like yours, common options are:
